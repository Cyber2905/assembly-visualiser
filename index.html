x86-64 stack visualiser

Type or paste a short assembly program, then step through it one instruction at a time. You'll see the registers and the stack change in colour as each line runs.

1. Enter your program

or try an example:

    Intel syntax. Supported: push pop mov lea add sub xor call ret leave jmp nop with the registers rax rbx rcx rdx rsi rdi rbp rsp (and 32-bit names like eax), numbers, and memory like [rbp-8]. Comments start with ; and lines like .globl main are ignored, so you can paste output from Compiler Explorer.

    The program starts as if it were a function that was just called: rdi = 5, rsi = 7, and the return address is already on the stack.

    Tip: use the left and right arrow keys.
